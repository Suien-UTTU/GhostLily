他放开了一只青蓝色的蜻蜓，任夏天迎来末尾。\
 \
半透明的塑料遮雨上有几个不易察觉的破洞，灼热的阳光从顶照下来时，会在地上发现这几个明显的光点。阿鹫喜欢蹲在水泥墙围出的角落眼神发直地盯着那几个光点。\
 \
湿热阴暗的脏地方经常出现虫子，粘在一切眼睛能看到的地方，和黄黑的油渍脏污为伴。支着棚子的铁栏杆上生了锈，凹凸的红褐腐蚀了大半表层，没有人擦掉这些锈迹，像是苔藓一样越生越多。\
 \
年轻人的欢笑声从水泥墙的另一端传来，捏扁的易拉罐被高高抛起来，飞到了阿鹫的家门前。\
 \
“没事啦！那边就是垃圾堆！”\
 \
无所谓的嬉闹渐渐远去，阿鹫伸出被尘土弄脏的手，够着易拉罐把它捡回来。他摇了摇，里面响起细微的水声，还有甜甜的味道从罐口飘出来。阿鹫吐出舌头，上下摇晃着罐子，几滴混浊的液体滴落在他的舌尖上。\
 \
他像一具死尸一样瘫在沥青地上，呆呆望着顶棚上的洞，光点照进他的眼瞳里，像是要在那上面点起火花。\
 \
慵懒昏沉的夏季，漫长的白昼无事可做只能打盹睡觉。阿鹫闭上眼就仿佛迎来了永久的暗夜，连求偶的蝉鸣也听不见了。\
 \
于是雨点打醒了沉睡的人。无星的黑幕抖落冰凉的水滴，从高空而落，砸落在污秽的大地上。\
 \
磨损过多的遮雨棚抵挡一波又一波攻击，找到空隙的雨滴从漏洞落下，如此巨大的攻势在塑料的遮板上打穿一个又一个洞，最后终于击破了破旧的屋顶，那雨水就全都浇在了阿鹫身上。\
 \
闪电劈打着夜晚。阿鹫茫然地望着天空，那里不再有他的遮雨棚，被冲破了最后一点防御，雨点冲掉了他身上的灰尘。\
 \
快要刺破耳膜的轰隆雷声催促阿鹫寻找一个安全的地方避雨，可哪里又是他能去的地方呢？他只把这曾经的垃圾回收处当家。\
 \
他在泥泞的道路上又滚又爬，满身的泥土被一次又一次洗净。衣服变成了累赘，那些布就消失了。阿鹫赤裸着，向未知的地点奔跑，他纯真的心几乎要消失在无尽的夜中。\
 \
他朝着一颗颗亮起的星星大喊起来，“让我飞起来吧！”\
 \
星光明明灭灭，泪与雨混杂从面庞滑下。那祈愿是不管用的，不管多少次祈祷，阿鹫也扎根在肮脏混乱的地上。\
 \
他伸出手抓起了什么，摔倒在泥中。
