现在正是黎明。而我在黎明停止的时刻被凶猛的怪物追杀着。\
 \
我记事起，这个世界就只有黑夜。母亲在我幼小的时候经常念叨着，“在你出生之前还是有白天的”，我那时候是不知道什么是白天的，于是我问了什么是白天，然后我就知道了什么是黑夜。从知道白天代表着什么起，我就不断盼望着黎明的到来。\
 \
我是渴望在熄灯后依旧能看清楚周围的，我想仔细看一看，不开灯的时候人长什么样，我最喜欢的画又是什么样，我的脸又到底是什么样。可惜就算有了白天我也没办法真的看见自己的脸，必须照着镜子才能仔细端详。但那也没关系，母亲说黑夜掩盖了一切，那大约有了白天，镜子也能忠实地映照我了吧。\
 \
现在我已经长大成人，我还是那样渴望能看到白日，只不过母亲已经有点疲惫了，她现在会说“黑夜也挺好的”。\
 \
一个本想多休息一会的日子，我躺在床上辗转反侧，脑子里全是些关于生活的繁琐思绪。就在我闭上双眼，要被床被拖进梦乡时，却被一个柔软的东西扑上了背。我挣扎着翻身，不耐地抬起眼皮，然后看见了母亲那张喜悦到快要哭出来的面孔。她本身就很老，现在做着这样扭曲的表情就让皱纹挤成了一团，像是一朵菊花，但更像是干得裂开缝的泥土。\
 \
我不想多看这样的表情，视线皮肤上那一层层褶皱时，我的心就像是要呕吐出来了，是从左胸腔翻涌上来的难受感觉。所以我垂下眼皮，就盯着母亲的衣服看，从被窝里伸出手拍着她的背，尽量放缓了声音问：“你怎么了妈妈？发生了什么事情吗？”\
 \
先是几声急促的喘息，在我怀疑她快把自己弄岔气时，她沙哑着嗓子，声音极其颤抖仿佛用尽了毕生勇气才能说话，“天……亮了……天亮起来了……！”\
 \
我讶异地抬头，刚要说怎么可能时就看见了母亲眼下像是露珠的泪水。\
 \
母亲紧紧搂住我，她只是不断重复着天亮了啊，终于天亮了之类的话。\
 \
我已经坐不住了，呆呆在床上被她抱着哭了两三分钟之后，我才终于理解了什么是‘天亮’。\
 \
怎么现在就天亮了呢？我还没做好准备呀……！难道白天的到来不应该是穿上漂亮的衣服，在虔诚的庆祝下来临吗？\
 \
我来不及思考更多了，糊弄地安慰了一番母亲，也懒得穿上鞋子，就滚下床然后跌跌撞撞往屋外跑去。\
 \
我觉得我什么都看不见了，就是一直往头顶望着，脚下一刻不停地跑着，随后我终于看到了被红色大片大片覆盖的天空。\
 \
腿脚的骨头都快被抽走了一样，我不由自主想要朝天下跪，痴迷在这片烈焰一样的色彩。\
 \
母亲不知道是什么时候来到的我身边，她也一样跪了下来，然后倚靠着我的肩膀，陶醉地望着天空。\
 \
“你快看那里，那个就是太阳，为我们带来白天的东西。”\
 \
我寻着母亲手指的方向看过去了，我激动地想要一睹太阳的真容。\
 \
可我什么都没看见，广阔无际泛着橙色白色的天空，什么都没有。可真要说那里似乎有一个指节大小的黑色圆点……\
 \
“没有啊妈妈，我什么都没看见……”我盯着那个圆点喃喃着，却半天都等不来回应，我扭头一看，看见了母亲的脸庞变得年轻起来，她脸上的皱纹都不见了，那土黄的肤色似乎被眼泪洗刷得白净起来……\
 \
“妈妈？妈妈……你怎么了啊？”我有些惊惧，去摇晃着母亲的肩膀，她不愿意回应我，手指依旧指着她说的太阳的方向，目光似乎涣散了，我凑近仔细一瞧，却没看见我的倒影。\
 \
“妈妈……”我的声音哑了。我想她应该是瞎了。\
 \
无论我怎么呼喊摇晃，她都不会醒来了，她以相当虔诚的姿势——朝天下跪指着她眼中的太阳，死去了。至少我觉得她现在是死了，我不愿意有一个年轻貌美但是像雕塑一样的母亲。\
 \
我站了起来，看着天空那个黑点有些不知所措，接下来该做什么我完全不清楚，就这么折回到床上睡觉好像也不太合适。我凝视着那个黑点，可能是盯得太久的缘故，那个黑点越扩越大了，它仿佛在生长一样，它不断扩大，伸展着自己的黑色，就像是有着生命……\
 \
恐惧刺痛了我的脚心，我不想承受这样的痛苦，慌忙地抬起脚，背对着那不断生长的黑点跑了起来。在我转身的时候它已经比一个盆还大了，它在扩大，它在侵蚀这新生的黎明……\
 \
我跑着，跑得肺被刀割似得疼，但是脚底的疼痛远比刀割还要更激烈，我只有不断地抬脚，抬起又放下，才能逃离片刻的疼痛，一瞬间我希望我会飞，脚替换成一双巨大无比的翅膀，只要不站在地上就不会疼了。\
 \
我跑着，跑着……看见天空的红色渐渐过渡到郁郁的橙色，它们很温暖，这颜色仿佛在向我微笑，要轻轻地包裹住我。我想到了婴儿时被母亲抱在怀里的感觉，但是脚底的疼痛使我抛弃了这温柔，我还要逃离身后的东西。\
 \
我得跑到有白天的地方去。我猜时间是暂停了，所以黎明才会被钻了个孔入侵。我又哭又笑，为这突然到来的命运感慨。我感觉我的身体和灵魂分开了，一个承受着剧烈的疼痛奔跑，一个在上面望着惬意轻松。\
 \
我以为我会跑到白天才会停下奔跑，但有一个人拦住了我的前方。\
 \
那是一个矮小瘦弱的人，其实我只要推开就可以继续跑了，可我却是下意识刹住脚步，甚至摔倒在地滚了一圈停下来了。\
 \
“你好呀……”怯懦的声音把我刚要燃起的怒火浇灭了些许，但我还是用不满的眼神来表示我的态度，我躺在地上仰望她说：“让我过去！”\
 \
“不行……你得先回答我，你是男人还是女人呀……”就算这个人看起来这样害怕我，可仍然是坚持把话说出来了。\
 \
我看她是一个软弱的女性，所以我回答：“我是男人，好了快让我过去吧。”\
 \
听到了我的回答，她并没有满意的样子，只是用一种悲伤的眼神望着我，她又摇了摇头说：“不，你不是男人呀……”\
 \
“那我是女人总行了吧！”我看着她柔和的下巴线条，有些不乐意地嘟囔。她可真是柔软啊，那脸颊圆圆的，毫无攻击性。\
 \
“不，你也不是女人呀……”她说。她似乎变得更悲伤了，落下了一串眼泪。\
 \
“那你还希望我是什么呀！”我不由得模仿起她那软绵绵又没力气般的声音，但我的情绪更加高昂，所以声音也更响亮了些。\
 \
“唉……”她一般摇着头一般叹气，然后从自己的裙子上用力扯下布料。我躺在地上就窥见了她裙底的风景，我也不好形容那是什么……那是仿佛被蚂蚁啃食过的双腿，和她可爱的样貌非常不相称。\
 \
她蹲在我身边，用撕下来的破布包住我的脚，我感觉到了她的温度还有她的眼泪。\
 \
“你要保护好自己的脚呀……”她小声地说，然后站了起来，为我让开了道路。\
 \
我这时才发觉自己的脚底应该被路上的砂砾磨破了，那疼痛后知后觉传达给我，我浑身一抖慌忙地想继续往前方跑。虽然我很讨厌脚上的布，但因为她的表情还有背后正追赶上来的东西，我穿着这舒适的‘布鞋’继续奔跑了起来。\
 \
我往前跑着，我想我应该是坚定的。我看见天空起了些微微的灰色，那虽然能看出让人害怕的黑色来，但它更亲和，让我不那么恐惧了。\
 \
脚上的布非常舒适，虽然有点妨碍奔跑，但是疼痛稍微减轻了些。可是这两块布会时不时散开，绊住我的脚步，每当我不得不停下把布拉紧，我就开始恐惧黑暗，还要被脚底钻心刺骨的疼痛折磨。\
 \
我一次又一次停下，然后起身把雕塑般的母亲和那双被蚂蚁啃过一样的双腿抛在了身后……\
 \
我问自己为什么不把布丢掉？那大概是有些喜欢脚被包裹带来的舒适……\
 \
我继续跑着，跑着……虽然有些磕磕绊绊，但我觉得我能稍微轻松一点跑去白天。\
 \
但是我看见前方有一场宴会。\
 \
国王和王后被簇拥在中心，聚客们看起来欢乐异常。我离他们还有点远，但隐约能听见，“庆祝太阳的到来！”这般的话。\
 \
我几乎要咆哮着说，去他妈的太阳！但我只是在心中呼喊，即使我觉得这声音的力量能震破天空，可这声音只会响彻我的心脏。\
 \
我放缓了脚步，不太情愿的往宴会走去。即使我不想沾上他们那愚蠢的快乐，但是我要去往前方就不得不穿过这场宴会。\
 \
“看看那是谁啊！一个脚上包着布的人！”我刚走过去，国王就指着我发出了嘲笑。我的耳朵应该是红起来了，那里十分滚烫燥热，不是因为害羞而是因为生气。这个国王根本就不明白，我脚上的布曾经是一位女性的裙摆。\
 \
“喂！脚穿布的家伙，要一起来喝酒庆祝太阳吗！”国王高高举着酒杯，向我发出了邀请。宴会的桌子上摆满了各式各样的美食和酒，人们吃喝过的残骸被随意扔在了地上，因为淑女的大裙子会遮住这些垃圾，所以没人去清扫这些东西。\
 \
“我不需要……”我对脚边的骨头还带着肉的骨头有些嫌弃，但我又不想用脚把它们踢开。我抬头冷冷地看着国王，然后说：“请你让开，我要过去。”\
 \
王后见气氛快要变得僵硬起来，赶紧站出来说：“这位朋友，太阳的出现是非常值得庆祝的啊，这象征我们长久的黑暗被驱散了，您就请喝一杯吧。”她用像是歌咏一般的腔调说话，这让我是头一次觉得语言是美丽的，我顿时有些局促，笨手笨脚接过王后递来的酒，然后一口喝完了。\
 \
我当然不是因为被说服了，我绝对不要庆祝太阳的到来。但是位高权重的人如此可亲可爱，我只好承受。\
 \
见我喝下酒，所有人都发出高昂的笑声，我一时之间被堵得发慌，只能呼出微弱的气，垂着头一语不吭，我知道我现在再怎么大叫都比不过一群人的大笑。\
 \
国王去搂着他的王后，十分愉悦的模样，他又说：“你的脸可真红啊，再喝一杯岂不是醉了！你走吧，但是得穿上新衣服，你和你的那些布看起来太好笑了！”\
 \
我想拒绝的，但是人群直接围拥了上来。无数手放在我的身体上抚摸，我羞恼得想要训斥，但是嘴也被人蒙住，我皱着眉盯着这群人，直到他们笑盈盈地散开，然后我看见我穿上了一身和国王王后他们一样华贵精致的衣服。\
 \
“你走吧！”国王高举着酒杯，宾客们继续闹哄哄起来。\
 \
我急急地走起来，然后越跑越快，终于把那吵闹的宴会甩在身后。脚底的疼痛也后知后觉的出现了，可能是因为衣服太过沉重，我总觉得脚越来越痛了，这种疼痛是越积越多，无论我跑得有多快它都不会减轻半分。\
 \
其实我也没办法跑得多快，因为我这一身华美沉重的衣裳。在宴会时我本来是想把它们脱下来丢掉的，但是现在我觉得，如果我跑到了有白天的地方，那这身衣服是刚刚好的。我本来就想热烈地庆祝白天啊。\
 \
我呼吸也越加沉重起来，我努力地跑着，时不时因为太累，喘着气左右摇摆地走着。\
 \
我几度以为我要摔倒了，我想就此停下不前。只有隐隐胜过期许的恐惧使我没办法停下来，即使我眼前发晕，腿脚已经脱力到可能会随时从我身上脱落。\
 \
我望向天空，泛白的颜色覆盖了我的世界，我感觉天空在向着我微笑……我嘴角努力上扬，想要回以一个笑容……\
 \
一边吃力地奔跑一边抬头仰望天空，这个姿势应该是非常滑稽的吧。我只是在脑子里想象了一下就对着天空笑了出来。我不觉得脚底疼痛了，或许是疼痛太过剧烈而变得麻木了吧，我觉得我超脱了肉体的疼痛，就要长出翅膀飞了起来，似乎连我身上的衣袍也被风吹得翻动了起来……\
 \
我跑了有多久？我还要再跑多久才能配得上时间的停止啊。这黎明为何就是不彻底的到来。\
 \
我在心中不断呼唤着，就在我以为自己要踩着空气登上通往天空的阶梯时。头顶传来了空灵的声音，\
 \
“停下来，我的孩子。”\
 \
我想要抬头望去，但一种莫名的胆怯阻止了我的动作，我感觉嘴唇似乎都在发颤，我问那个声音，“你是谁？”\
 \
“我是上帝，孩子。”\
 \
这一句回答逼停了我的脚步，我仍旧不敢抬头，只是呆呆地盯着前方看，那尽头似乎有永恒的白日和丰茂的土地。\
 \
“你既然是上帝，那为什么要阻拦我向前的脚步？”我用愤怒的声音责问他，但其实我因为能停下来歇息一会而感到一些开心。\
 \
“因为我不想再看见你受苦，我的孩子。你该停下来休息了，否则你的身体会崩溃。”那声音明明如雷霆般震耳，让人心生敬畏又想要依靠。\
 \
“我不可以停下来！”\
 \
“那你为什么要向前。”\
 \
“因为我要跑到白天那边去啊！”我大吼出这句话的时候头仰起来了一点，视线窥见了一点白色的衣角就又赶紧低下了头不去直视。\
 \
“你去白天那里做什么？黑夜也一样好，你应当留在黑夜，去接受黑夜。”上帝用绝对的话来否定我向前的行动，他是宽厚仁慈的上帝而不是什么愿望都会实现的上帝。\
 \
我不敢说出我厌恶黑夜这件事情，我沉默地低着头，然后听到了一声叹息。\
 \
“那换下你的衣裳吧，我的孩子。”上帝不由分说地，用一件纯白轻盈的袍子换掉了我身上华美的衣服。\
 \
这件袍子朴素低调，低着头就能直接看见脚趾。\
 \
“人们不应该穿这样累赘的衣服，你这样才是极好的。”我听着上帝的声音渐渐远去，我想他应当是满意地离开了。\
 \
这身袍子穿起来确实更加轻松，可我却感到一阵空落落的……虽然那些华美的衣服我并不喜欢，但现在总感觉缺失了什么一样。\
 \
我迷茫地向前走着，迎面吹来的风带起了我的衣袍。袍子确实轻得让人想要飘起来一样，但它并不防寒，我感觉身上一阵阵发冷，为了暖和起来我只能抬起脚跑起来。\
 \
我时而感觉自己脚步轻盈的走着，时而感觉自己急促地奔跑，我恍惚地感觉自己宛如刚被从子宫摘下的婴孩，无人告诉我应该怎么做，只能飘一样地去往前方。\
 \
我想我应该是离白天很近了，我都不知道自己到底跑了多久，只是紧紧盯着正前方，重复着一个单一的动作。\
 \
应该是在不远的地方了，因为我看见了瑰丽的颜色，无法形容这样的色彩是多么梦幻，它们可以是任何颜色，但好像我能数出的颜色大体就那几种……我认识的颜色会不会太少了？我怎么知道白天的白色是哪样的呢？\
 \
这蔓延在心中的恐慌感使我的脚底再次剧烈的疼痛，至少我知道黑夜的颜色是什么样的，我不能被追赶上来。\
 \
我只是加速奔跑着。\
 \
奔跑的过程单一且乏味，不过我已经能如同刚开始那样专心地跑。直到我视线的角落好像出现了一个影子……\
 \
那究竟是什么？影子越来越明显，然后我彻底看清了——\
 \
一个正在奔跑的人。除了我以外，正在奔跑的人。他的姿势是那么的滑稽啊……他似乎是经历了和我一样的事情，因为他身上穿着白色的袍子。\
 \
另一个奔跑的人似乎也注意到了我，我们两个人越靠越近，像是磁石在彼此吸引一样。\
 \
我忍不住捏着嗓子喊：“喂！你好呀！”\
 \
“你好！”他用一种激昂的情绪向我回应。\
 \
我们想拥抱在一起，为这漫长的旅途终于有一个同伴而快乐。可是不行，因为还得继续前进，这也就成了小小的遗憾。\
 \
“你从哪里来？”我不由得问他，然后又自己回答了起来，“对……你应该也是从黑夜来的吧。那你是要去白天吗？”\
 \
“是啊，我很想去白天。”他的回答不出预料，可我听到后还是万分喜悦，这超然的情绪让我觉得之前的任何经历和劳累都不值得一提。\
 \
我屏住呼吸，然后悄声问，“你为什么要去呢？”\
 \
“因为我想看清楚黑夜过去后到底是什么样的。不过我现在好像能清楚的看见你，你是一个美丽的人啊。”他用赞叹的口吻说着。我就因为他的话头脑感到一阵眩晕，自己似乎飘飘然了起来……\
 \
我也回望过去，仔细端详着他的脸庞。我应该是从来没有这么看过一个人的脸吧，我数了数他有多少个眼睛，他有几个嘴巴，他有几个耳朵和鼻子，我一个个数完后发自内心地笑起来，“你真是长得和我一样啊……你也很美丽。你是谁……？”我放柔了声音，害怕太大的音量会击破彼此间小小的庆幸。\
 \
“我是爱人呀。”他说。\
 \
爱人渐渐落后于我，我没办法慢下来，因为我要维持奔跑的姿势。我不断地大喊确认爱人还在我的身后，直到声音越来越远。\
 \
我回头看去，看到了深深的黑色，它已经吞噬了我身后的一切，现在就要吞噬我的爱人。\
 \
如果我停下来就会被那无比漫长的黑夜给吞掉了吧，恐慌与疼痛回到了我的身上，我身上的白袍子因为奔跑的风而飞走，我不敢在回头，我恐惧着那片黑夜了。\
 \
爱人的尾音回荡在了我的耳旁，我听不清那说得是什么。我只能浑身赤裸，不顾疼痛疯狂地向前跑着，不断地跑着……\
 \
风灌进了我的耳朵里，又灌进了我鼻腔和嘴里，我感到一种生硬的冷，这种冷像是刀子一样割着内脏。我又感觉到风进到了我的眼睛里，我的泪水不断地落下，我似乎听见了眼泪滴落在地的声音。\
 \
我的身体早已经疲惫不堪了，可我不知道，不知道该怎样停下。那让人幸福的白天真的会存在吗？为什么此时我只能看见黑夜的颜色不断地向前延展，我就要跑不过它了……\
 \
我不敢再看着前方，闭着眼睛闷头朝前继续跑着。我觉得时间很快，又很慢，在我奔跑的思考又停止下来了。\
 \
直到我的头砰得撞到了什么东西，我跌坐在地痛苦呻吟着。\
 \
我睁开眼睛想看看又是什么东西拦住了我的去路，但是泪水让我的眼前一片模糊，我不断地眨着眼，然后看到一片炫目的白色……\
 \
这一定是白天了！这里一定就是白天了！\
 \
欢欣雀跃着，我的心脏砰砰跳起来，现在我朝天望去都只能看到一片纯洁的白……这似乎不够超乎想象，但我也十分满足。\
 \
眼泪又一次涌出来，模糊了一切。我好像听见了母亲的声音，她在我的耳边低声呢喃，那就是太阳啊……\
 \
那就是太阳啊……我的手颤抖地朝前方伸过去。我的指尖好像触摸到了类似布质的东西，说实话那像是衣服的感觉。我不知所措地往下一拉，结果陷入了某个柔软的怀抱里——我跌倒在了土地上，随后感觉头顶有什么东西盖了下来。\
 \
母亲的声音不断地在我耳边响起来，因为我看到了，撕下了幕布的假象……\
 \
我觉得这个怀抱十分温暖，渐渐地、渐渐地……融化了。我看见了无比庞大的黑夜，就连我也睡了进去。\
 \
那沉沉的梦境包裹了我的一切，我再也动弹不得。\
 \
我抵达了黑夜的终点。
